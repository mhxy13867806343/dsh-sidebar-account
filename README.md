# dsh-sidebar-account

侧栏底部多一行：**余额** + **充值**。

```
┌──────────────────────────────┐
│ ↑  2.0.16 → 2.0.17   [更新]   │   ← dsh-desktop-updater
├──────────────────────────────┤
│ 👛 余额  ¥1.96       [充值]   │   ← 本插件
├──────────────────────────────┤
│ (头像) token 患者              │   ← 宿主自带
└──────────────────────────────┘
```

- 左边显示**充值余额**（和「设置 → 账号与余额」里那个 ¥1.96 是同一条数据）；
  只有赠金时显示赠金；鼠标悬停可以看到「充值余额 / 赠金余额」的完整拆分。
- 右边「充值」按钮点了**直接打开充值页**（系统浏览器），链接就是账号接口
  `getState().links.topUpUrl` —— 和设置页「充值」按钮用的是同一个地址。
- 未登录时显示「未登录」，按钮依然可用（充值页那边会让你登录）。
- 收起成窄栏时变成一个钱包图标按钮，点了同样去充值。

## 数据来源与刷新

数据全部来自宿主已经生成好的远端命名空间 `ctx.remote.account`（本插件没有自己的 Host 服务）：

| 调用 | 用到什么 |
| --- | --- |
| `ctx.remote.account.getState()` | `status`（是否登录）、`links.topUpUrl`（充值地址） |
| `ctx.remote.account.getBalance({ version, locale, timezoneOffsetSeconds })` | `value`（充值余额钱包）、`bonusWallets`（赠金） |

刷新时机：挂载时、窗口重新获得焦点 / 页面重新可见时（30 秒节流）、每 10 分钟一次。

金额按设置页同样的规则格式化：**向下截到两位小数**、小于 0.01 显示 `<¥0.01`、千分位分组；
全程走字符串截断，不经过浮点数，避免 `1.005` 这类舍入坑。

## 备注

- 只读：本插件不写任何账号状态，也不发起登录/登出，只读余额 + 给一个充值链接。
- 不 import 任何 Harness 客户端包，样式只用 `--dsw-alias-*` 主题变量，深浅色自动跟随。
- 排序：`sidebar.footer.action` 里 `order: 110`，排在更新行（100）下面、账号行上面。
